# Роадмап

RTS на Rust в духе Generals и «В тылу врага», по масштабу и механикам ближе к Company of Heroes.

## Цель версии 1.0

Маленькая, но законченная игра: одна сторона (зеркальный матч), одна карта на двоих, бой против ИИ.

**Входит:**

- 6 юнитов: строитель, стрелковый отряд, противотанковый отряд, разведмашина, танк, артиллерия
- 5 зданий: штаб, казарма, завод, источник ресурса, турель
- один ресурс, простая экономика
- направленная броня, укрытия для пехоты, снаряды с траекторией, разрушаемые здания по стадиям
- туман войны, миникарта, интерфейс, звук, эффекты выстрела и взрыва
- ИИ-противник одного уровня сложности
- победа: уничтожить штаб
- запуск на macOS, Windows и Linux

**Отложено до дополнений:** сеть, другие стороны, авиация, ракеты и ядерный удар, способности генералов, кампания, редактор карт, сохранения.

Любая новая идея проверяется вопросом: нужна ли она для этого списка. Если нет, она идёт в `docs/ideas.md`.

## Принятые решения

| Вопрос | Решение |
| --- | --- |
| Движок | Bevy только для клиента: рендер, ввод, звук, интерфейс |
| Симуляция | отдельный крейт `sim` без зависимости от Bevy |
| Хранение юнитов | простые структуры в массивах, идентификаторы с поколением, без ECS |
| Числа в симуляции | фиксированная точка с первого дня |
| Тик | 30 в секунду, клиент интерполирует |
| Карта | сетка клеток с высотой и проходимостью |
| Вход в симуляцию | только команды (игрок, ИИ, реплей, позже сеть) |
| Выход из симуляции | состояние и события |
| Сеть в будущем | детерминированный lockstep |
| Бюджет | 300 юнитов при 60 кадрах на ноутбуке без дискретной видеокарты |

## Как работать с этим файлом

- Один шаг это одна сессия с агентом и 100-300 строк изменений.
- Шаг закрыт, когда тесты зелёные, diff прочитан и понят, сделан коммит, здесь поставлена отметка.
- Подробно расписана только текущая веха. Шаги дальних вех предварительные и уточняются перед началом вехи.
- Перед вехой создаётся `docs/stages/NN-имя/spec.md` с задачами и критериями готовности.
- На каждый шаг агент создаёт файл `docs/stages/NN-имя/N.M-имя.md`: сначала план, после реализации итог. Порядок описан в `docs/process.md`.
- Значимые решения записываются в `docs/decisions.md`.

Размер вехи: **М** малая, **С** средняя, **Б** большая.

# Часть 2. Дополнения после 1.0

Порядок предварительный. Каждое дополнение проходит тот же цикл: файл этапа, шаги, тесты.

1. **Ракеты и ПВО.** Высота в симуляции, наведение, баллистические ракеты, перехват.
2. **Подавление и мораль.** Отряд под огнём залегает и хуже стреляет.
3. **Исходы гибели техники и ветеранство.** Взрыв боекомплекта, пожар, выбитый экипаж; опыт за уничтожения.
4. **Сеть.** Lockstep, релей, лобби, поиск расхождений по хешам систем.
5. **Авиация.**
6. **Супероружие и ядерный удар.** Ударная волна, типы урона, радиация на поле с затуханием, большой эффект на клиенте.
7. **Вторая и третья стороны.** Генералы и их способности.
8. **Сохранения.**
9. **Редактор карт.**
10. **Развитие ИИ.** Уровни сложности, подбор параметров самоигрой, эксперимент с обучаемым ботом.
11. **Кампания.**
12. **Продвинутая графика.** Апскейлинг, объёмные эффекты.

# Сквозные правила

- Симуляция не зависит от Bevy, времени, файлов и случайности без сида.
- В логике нет float и обхода `HashMap`.
- Клиент только читает состояние и события, изменения идут через команды.
- Отладочные команды записываются в реплей наравне с игровыми.
- Параметры юнитов и оружия лежат в файлах данных.
- Версии Bevy и ключевых крейтов зафиксированы, обновление это отдельный шаг.
- Раз в несколько вех игра запускается на самой слабой доступной машине.
- Играть в текущую сборку нужно с первой недели, даже кубами.
